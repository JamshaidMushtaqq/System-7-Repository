As part of Day 2, I built a menu-driven Student Record Manager using Python.

### Features

- Add a new student record.
- View all saved student records.
- Store student names, roll numbers, and marks.
- Prevent duplicate roll numbers.
- Validate student names, roll numbers, and marks.
- Handle invalid marks and file-reading errors.
- Save student records in a JSON file.
- Load previously saved records when the program runs again.
- Exit the program using a menu option.
